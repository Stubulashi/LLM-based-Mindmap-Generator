# 板块二「实现细节类（技术落地）」工作清单

## 一、总体说明与划分依据

### 1.1 板块定位

本板块承接 AI MindMap Agent 提交工作中「如何实现」层面的全部工作，面向技术落地，回答"每段代码如何写、参数如何设定、缺陷如何定位与修复、环境如何配置"。内容包括程序调整、代码改动、技术参数调优、配置与调试，产出以可运行的代码、配置、测试与调试结果为主——核心源码、前端界面、评估框架程序、测试套件与版本管理。质量要求在于技术实现的正确性与健壮性。

### 1.2 划分依据（书面化表述）

项目全部工作按认知属性与产出属性分为两类，互为表里：

- 板块一「统筹/文书类」：承担"需要实现什么"层面工作，即需求定义、方案设计、框架论证与流程规划，产出为论述性、规范性、分析性文档。
- 板块二「实现细节类」：承担"如何实现"层面工作，即技术方案的具体落地，偏重代码、配置与调试，产出需更多的工程性思考。

板块二按板块一提供的需求/方案文档与契约设计实现代码，并为板块一提供实现事实、运行数据、实验记录与定版 Git tag。两板块合并后 100% 覆盖《Submission instructions.pdf》全部 20 项要求（报告类 R1–R6 计 6 项、章节类 S1–S8 计 8 项、代码类 C1–C6 计 6 项），且工作量大体均衡（约 50% : 50%）。

### 1.3 覆盖范围声明

本文件为板块二专属清单，其 PDF 覆盖子表（见第七章）与板块一清单中的覆盖子表合计即完整覆盖核对表，无遗漏、无重复。
